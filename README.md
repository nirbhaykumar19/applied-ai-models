# Applied AI Models

A collection of **practical AI, Machine Learning, and Deep Learning implementations** built using Jupyter notebooks.

This repository contains experiments and implementations related to:

- Generative AI
- Neural Machine Translation
- Computer Vision
- OCR using LLMs
- Deep Learning architectures
- Transformer models

The goal of this repository is to maintain a **growing library of applied AI models and experiments**.

# Example Results

### Variational Autoencoder Results

Standard **VAE (β = 1)** produces higher reconstruction quality with sharper generated images.

**β-VAE (β > 1)** improves latent space disentanglement but produces slightly blurrier outputs.

### Neural Machine Translation

The transformer model learns alignment between English and Spanish tokens using attention mechanisms.

### OCR + LLM

Images are converted to text using OCR pipelines enhanced with LLM-based processing.
